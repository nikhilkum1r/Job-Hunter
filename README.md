# Horizon Job Hunter

An autonomous job application automation engine designed to discover, analyze, and apply for jobs worldwide.

## Features

- **Autonomous Discovery**: Searches the web for relevant job postings.
- **Match Analysis**: Evaluates job descriptions against user profiles.
- **Automated Applications**: Handles form filling and submission efficiently.
- **Integrated Dashboard**: Real-time telemetry and management of application pipelines.
- **Multi-Model AI Support**: Leverages OpenAI, Anthropic, and Gemini for intelligent decision making.

## Tech Stack

- **Backend**: Node.js, TypeScript, Playwright
- **Frontend**: React (Vite), CSS3
- **Database**: SQLite

## Setup

1. Install dependencies:
   ```bash
   npm install
   cd dashboard && npm install
   ```
2. Configure environment variables in `.env`.
3. Start the application:
   ```bash
   npm start
   ```
